# Конфигурация (`.env`)

`mivta` читает настройки из переменных окружения и файла `.env` в рабочей директории (переменные окружения процесса имеют приоритет над `.env`). Проверить корректность конфигурации без запуска бота:

```bash
python -m mivta --check
```

---

## Полная таблица параметров

### Обязательные и провайдер перевода

| Переменная | По умолчанию | Описание |
| :--- | :--- | :--- |
| `BOT_TOKEN` | *(обязательна)* | Токен бота от `@BotFather` (формат `123456:ABC...`). |
| `TRANSLATOR_PROVIDER` | `google` | Основной провайдер: `google`, `groq`, `gemini`, `openrouter`, `openai`, `deepl`, `libretranslate`. |
| `TRANSLATOR_API_KEY` | `""` | Ключ API (обязателен для `groq`, `gemini`, `openrouter`, `openai`, `deepl`). |
| `TRANSLATOR_API_URL` | *(по пресету)* | Переопределение базового URL API. При передаче `API_KEY` на не-loopback хост требуется `https://`. |
| `TRANSLATOR_MODEL` | *(по пресету)* | Переопределение модели для LLM-провайдеров. |
| `TRANSLATOR_TIMEOUT` | `5.0` | Таймаут HTTP-запроса к провайдеру в секундах (`> 0`). |
| `ALLOW_INSECURE_HTTP_API` | `false` | Разрешить `http://` с `API_KEY` для не-локальных адресов (например, Ollama в закрытой домашней/VPC сети). |

### Резервирование и глоссарий

| Переменная | По умолчанию | Описание |
| :--- | :--- | :--- |
| `TRANSLATOR_FALLBACK_PROVIDER` | `""` | Резервный провайдер или список через запятую (например, `google` или `libretranslate,google`). |
| `TRANSLATOR_FALLBACK_API_KEY` | `""` | Ключ API для резервного провайдера (если отличается). |
| `TRANSLATOR_FALLBACK_API_URL` | `""` | Кастомный URL для резервного провайдера. |
| `TRANSLATOR_FALLBACK_MODEL` | `""` | Модель для резервного LLM-провайдера. |
| `TRANSLATOR_GLOSSARY` | `""` | Слова и названия через запятую, которые не должны переводиться. |

### Настройки перевода и интерфейса по умолчанию

| Переменная | По умолчанию | Описание |
| :--- | :--- | :--- |
| `DEFAULT_SOURCE_LANG` | `auto` | Исходный язык для новых пользователей (`auto` или ISO-код). |
| `DEFAULT_TARGET_LANG` | `en` | Целевой язык по умолчанию для новых пользователей. |
| `DEFAULT_SWAP_LANG` | `""` | Парный язык двустороннего авто-разворота `⇄` по умолчанию (например, `ru` или `pl`). |
| `DEFAULT_STYLE` | `neutral` | Стиль по умолчанию: `neutral`, `casual`, `formal`. |
| `DEFAULT_UI_LANG` | `ru` | Язык интерфейса бота (`ru` или `en`), если Telegram не передал `language_code` пользователя. |
| `INLINE_EXTRA_LANGS` | `""` | До 3 доп. языков карточек в Inline Mode по умолчанию (например, `pl,de`). |
| `INLINE_STYLE_VARIANTS` | `true` | Показывать карточки сразу всех 3 стилей в Inline Mode (для провайдеров со стилями). |
| `INLINE_DEBOUNCE_MS` | `180` | Окно коалесинга быстрых нажатий в Inline Mode на холодном кэше (`0..2000` мс; `0` — без ожидания). |

### Режим Webhook (опционально)

Если `WEBHOOK_URL` пуст, бот работает через **Long Polling** и не открывает входящих портов.

| Переменная | По умолчанию | Описание |
| :--- | :--- | :--- |
| `WEBHOOK_URL` | `""` | Публичный `https://` адрес (например, `https://bot.example.com/webhook`). Включает режим Webhook. |
| `WEBHOOK_SECRET_TOKEN` | *(авто)* | Секрет заголовка `X-Telegram-Bot-Api-Secret-Token` (`[A-Za-z0-9_-]{1,256}`). Если пуст — генерируется криптографически при каждом запуске. |
| `WEBHOOK_HOST` | `127.0.0.1` | Локальный адрес прослушивания `aiohttp` (рекомендуется `127.0.0.1` за Nginx/Caddy). |
| `WEBHOOK_PORT` | `8080` | Локальный порт (`1..65535`). На том же порту отвечает `GET /healthz`. |
| `WEBHOOK_PATH` | `/webhook` | HTTP-путь приёма апдейтов (не может быть `/healthz`). |

### Хранилище и эксплуатационные лимиты

| Переменная | По умолчанию | Описание |
| :--- | :--- | :--- |
| `DATABASE_PATH` | `data/mivta.db` | Путь к SQLite-базе настроек пользователей (`:memory:` для тестов). |
| `MAX_TEXT_LENGTH` | `500` | Максимальная длина переводимого сообщения (`1..4096`). |
| `CACHE_TTL` | `300` | Время жизни записей RAM-кэша в секундах (`0` отключает кэш). |
| `CACHE_MAX_SIZE` | `512` | Максимум записей в LRU-кэше (`0` отключает кэш). |
| `RATE_LIMIT_PER_MINUTE` | `30` | Скорость пополнения лимита запросов на одного `user_id` в минуту. |
| `RATE_LIMIT_BURST` | `15` | Максимальный разовый всплеск запросов на одного `user_id`. |
| `MAX_CONCURRENT_TRANSLATIONS` | `20` | Общий семафор одновременных запросов к внешнему API переводчика. |
| `LOG_LEVEL` | `INFO` | Уровень логов: `DEBUG`, `INFO`, `WARNING`, `ERROR`, `CRITICAL`. |
