# Провайдеры перевода, резервирование и глоссарий

Пакет `mivta.translator` изолирован от `aiogram`, SQLite и конфигурации приложения: все провайдеры работают поверх общего пула соединений `httpx.AsyncClient` с жёстким таймаутом и потолком тела ответа `1 MiB`.

---

## Поддерживаемые провайдеры

| `TRANSLATOR_PROVIDER` | Ключ API | Стили (`neutral` / `casual` / `formal`) | Модель / Узел по умолчанию | Особенности |
| :--- | :---: | :---: | :--- | :--- |
| `groq` | Да | 1 батч-вызов на 3 стиля | `llama-3.3-70b-versatile` (`api.groq.com/openai/v1`) | Минимальная задержка среди LLM (~150–250 мс), одношаговый авто-разворот `⇄` на одном алфавите. |
| `gemini` | Да | 1 батч-вызов на 3 стиля | `gemini-2.5-flash` (`generativelanguage.googleapis.com`) | OpenAI-совместимый эндпоинт Google AI Studio, быстрый мульти-стилевой JSON. |
| `openrouter` | Да | 1 батч-вызов на 3 стиля | `openai/gpt-4o-mini` (`openrouter.ai/api/v1`) | Доступ к любой модели OpenRouter через `TRANSLATOR_MODEL`. |
| `openai` | Да | 1 батч-вызов на 3 стиля | `gpt-4o-mini` (`api.openai.com/v1`) | Работает с официальным API OpenAI и любым совместимым сервером (Ollama, vLLM, LiteLLM) через `TRANSLATOR_API_URL`. |
| `deepl` | Да | Нативный `formality` | `api-free.deepl.com` (`:fx`) или `api.deepl.com` | Автовыбор Free/Pro эндпоинта по суффиксу `:fx` ключа, сохранение разметки через XML-теги `<sN>`. |
| `libretranslate` | Опционально | Нет | `libretranslate.com` или свой URL | Удобен для полностью автономного self-hosted контура. |
| `google` | Не нужен | Нет | `translate.googleapis.com` → `clients5.google.com` → `translate.google.com` | Работает «из коробки» только с `BOT_TOKEN`; при `HTTP 429` на подсети VPS автоматически переключается на рабочий узел и запоминает его. |

## Цепочка отказоустойчивости (`FallbackTranslator`)

Через `TRANSLATOR_FALLBACK_PROVIDER` можно задать один или несколько резервных провайдеров через запятую:

```dotenv
TRANSLATOR_PROVIDER=groq
TRANSLATOR_API_KEY=gsk_...
TRANSLATOR_FALLBACK_PROVIDER=google
```

Правила переключения:
- При таймауте, `HTTP 429/456` (квота), `HTTP 401/403` или `5xx` на основном провайдере запрос прозрачно уходит в следующий провайдер цепочки.
- Локальные ошибки валидации (пустой ввод, превышение `MAX_TEXT_LENGTH`) завершаются сразу и не расходуют вызовы резервных провайдеров.
- Если резервный провайдер требует отдельного ключа или URL (например, `deepl` или локальный `libretranslate`), они задаются в `TRANSLATOR_FALLBACK_API_KEY`, `TRANSLATOR_FALLBACK_API_URL` и `TRANSLATOR_FALLBACK_MODEL`.

## Глоссарий непереводимых терминов

Переменная `TRANSLATOR_GLOSSARY` принимает список имён собственных, брендов и терминов через запятую:

```dotenv
TRANSLATOR_GLOSSARY=mivta, Kubernetes, Play2Go, PostgreSQL
```

- Для **LLM-провайдеров** (`groq`, `gemini`, `openrouter`, `openai`) термины передаются в системной инструкции модели, чтобы модель корректно склоняла окружающий текст, оставляя сами слова без перевода.
- Для **классических провайдеров** (`google`, `deepl`, `libretranslate`) и смешанных цепочек резерва `mivta` маскирует совпадения по границам слов токенами-плейсхолдерами до отправки и восстанавливает их после перевода.

## Двусторонний авто-разворот (`⇄`)

Когда у пользователя задан парный язык (`/swap ru` или `DEFAULT_SWAP_LANG=ru` при целевом `en`) и исходный язык стоит в `auto`:

1. **Разные письменности (`en ⇄ ru`, `en ⇄ uk`, `en ⇄ he`, `en ⇄ zh` и др.)**: направление определяется локально по Unicode-скрипту текста за `0` дополнительных сетевых вызовов.
2. **Один алфавит (`en ⇄ pl`, `en ⇄ de`)**:
   - LLM-провайдеры определяют язык и переводят в нужную сторону за **1 вызов**;
   - детекторные провайдеры (`google`, `deepl`) разворачивают направление автоматически, если определённый исходный язык совпал с целевым.
